# Solis_Knomi v1.1.0 — WebUI 单管理员认证

适用范围：KNOMI V1、ESP32-D0WDQ6-V3、4 MB Flash、无 PSRAM，`knomiv1-4mb` 环境。其他板型/环境未验收。

## 变更

- 首次未设管理密码时 WebUI 开放；可在原「设置」页下方设密。
- 设密后使用浏览器原生 HTTP Basic 登录，用户名固定为 `admin`，没有公开默认密码或操作员凭据文件；登录后可修改密码。
- 页面、所有 API、文件访问、OTA、未知路由/方法以及 WebSocket 握手统一受保护。未认证/错误凭据返回 401 和 Basic challenge，WS 不提前升级为 101。
- 设备 NVS 只保存版本化盐/校验值。已有认证存储异常时不重新开放；改密后旧 WS 认证代次立即失效，异步日志发送前再次检查。
- 构建时验证 ESP-IDF 4.4.7 的实际握手调用经过认证包装器；普通构建不再触发可选上传工具依赖安装。未修改 OTA 请求业务、主题或 Wi-Fi 显示流程。

进度算法、显示选择和 Moonraker 通信未改。WebUI 密码不用于 Moonraker，固件没有新增 Moonraker API Key/JWT 支持；部署侧需要仅信任 KNOMI 已确认的固定 IP。

## 已验证

- 原生回归 3/3 通过：195 个路由/凭据/WS 矩阵场景，另有真实认证/密码 API 回调、NVS 错误码、重启持久化模型、改密及会话失效断言。SDK/NVS 为边界替身，非真实硬件全覆盖。
- WebUI 生产打包与 `knomiv1-4mb` 构建通过；RAM 51,176 / 327,680 字节（15.6%），Flash 1,189,333 / 1,507,328 字节（78.9%）。实际 ELF 握手调用目标已核对。
- 设备一次仅固件 OTA 返回 200 OK，重启后 WebUI 与候选资源逐字节一致，首次状态 `configured=false`；用户随后自行设密并验收。
- 设密后现场只读负向检查共 12 项：匿名/随机错误凭据访问页面、API、文件/未知路径和 WS，均为 401 + Basic，WS 未升级。

## 已知限制与未验证项

- 全量 `svelte-check` **未通过**：基线 `f2cadf6` 与本版均为相同的 24 项诊断，分布于既有 App/Theme/ThemeFile；新 Password 组件无诊断。生产打包、原生回归及上述现场验收通过，因此没有扩大到无关类型修复；不将本版描述为全量类型检查通过。
- 进度显示留待下次打印确认；未由代理实机代验改密和再次重启后的密码持久化（原生模型回归已覆盖）。不声称完整硬件/E2E 回归完成。
- HTTP Basic 不加密传输，仅用于可信局域网，不向公网开放。首次/NVS 整体擦除后是开放状态，应及时设密；忘记密码无远程绕过入口，需另行授权本地维护。
- 原始 coredump 仍是敏感材料；不保证任意崩溃转储不含瞬时请求内存。
- 为保持与已验收固件完全一致，未更改内嵌上游页脚版本元数据（`f052bef`）。Solis 发行身份以本标签、资产哈希和 `build-info.json` 为准。
